## 0. 一分钟结论

1. 有 **3 个「设置项点了没反应」** 的真 bug：启动后息屏（D1）、scrcpy 原生引擎回退（README 承诺的开关根本不存在，见 §3）、以及一整套系统动作键（返回/Home/多任务/音量/电源）在界面上无路可走（D2）。
2. 最划算的一刀是**给所有 adb 调用加超时**（D5）：现在只有 helper 列表那条有超时，transport 半死时界面会永久转圈且不报错，把已有的重连链路一起带崩。
3. 图标链路有一处**并发丢写**（D4）+ 全量重写缓存文件，300 个应用时列表还有几处可预见的卡顿（O5）。
4. **文档比代码更旧**：`README.md` 教的构建命令有一对名字与语义相反，`PRINCIPLE_DOCUMENT.md` 有五个引用指向不存在的文件。这对后面接手的人（和 agent）是实际伤害。
5. 好玩且便宜的：helper 里那个「跳到无线调试二维码页」的 Activity，Mac 侧从来没调用过（F7）。

## 2. 优化（不改行为，但明显减负）

### 结构与工程

- **O0 ✅ 仓库自己的 lint 门现在是红的**：`npm run lint` 直接失败（`ERROR: "lint:oxlint" exited with 1`），6 条全是 `no-unused-vars`：`electron/menu.js:1` 的 `BrowserWindow`、`electron/iconImage.js:7` 的 `pathExists`、`electron/adb.js:2` 的 `spawn`、`electron/adb.js:13` 的 `currentScrcpyConfig`、`tests/electron/iconImage.test.js:12` 的 `composeMacosIconPng`、`:22` 的 `pngSize`。

- **O1 拆 `electron/adb.js`（1534 行，8 个职责）**：adb 执行与错误归一（`:43-124`）、输出解析（`:136-160`）、mDNS 发现与设备名（`:162-329`）、健康与重连（`:344-388`）、应用缓存与图标（`:394-749`、`:751-974`）、稳定标识别名（`:490-622`）、应用操作（`:980-1205`）、设备信息（`:1207-1412`）、IPC 注册（`:1414-1534`）。`tests/electron/` 已经按这些主题分了文件，主进程按同一刀切下去最自然。

### 4.3 有趣 / 差异化（这些是 AndroMeld 没有的）

- **H1 专注投屏**：镜像会话开着时自动静音 Mac 通知（Do Not Disturb API）+ 设备侧进入免打扰，会话结束自动恢复。对「投屏看视频/演示」是实打实的体验差。
- **H2 菜单栏常驻会话**：把当前镜像会话放进 macOS 菜单栏（Electron `Tray`），一键聚焦/关闭/接回（接回逻辑已有：`am display move-stack`）。和已经做好的 ⌘Q 语义（`electron/menu.js`）是一套。
- **H3 「工作台」预设**：把两块以上镜像的窗口位置/尺寸/应用存成一套布局，一键恢复（`mirrorWindowBounds` 已在 `electron/mirror/options.js:125` 算好初始尺寸，缺持久化与恢复）。
- **H4 Presenter 模式**：只推画面、Mac 侧当遥控器（翻页/音量/播放暂停走 F4 的动作键），配合全屏启动已有开关 —— 手机当演示笔用。
- **H5 软键盘策略**：scrcpy 的 `displayImePolicy` 我们现在完全忽略（`options.js` 未映射）。加个开关避免「投屏时手机弹出键盘占掉半屏」。
- **H6 使用时长本地统计**：`dumpsys usagestats` shell 可读，首页给「今天最常用」，并给 MRU 排序（路线图 P1-4）提供真实数据源。
- **H7 镜像画面标注/截图卡片**：镜像里截一帧，连应用名+时间戳存成卡片（截图能力见 F1，图标能力已在 `iconImage.js`），做「今天在手机上看过的东西」留痕。
