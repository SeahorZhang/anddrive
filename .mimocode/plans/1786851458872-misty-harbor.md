# 手机App列表获取方案

## 背景

当前项目 `anddrive_next` 已有ADB基础设施和AppList.vue组件骨架，但数据是mock的。需要实现通过ADB获取Android手机已安装app列表（图标+名称）。

## 需求确认

- **App类型**：全部app（包括系统app）
- **图标获取**：懒加载（先显示名称，图标异步加载）
- **加载性能**：分页/滚动加载（先加载前20个，滚动加载更多）

## 技术方案

### 1. ADB命令选择

| 需求 | ADB命令 | 说明 |
|------|---------|------|
| 获取app列表 | `pm list packages -3` | `-3`只获取第三方app，去掉则获取全部 |
| 获取app名称 | `dumpsys package <package> \| grep labelRes` | 需要进一步处理 |
| 获取app图标 | `aapt dump badging <apk>` | 需要先获取apk路径 |

**推荐方案：使用 `cmd package list packages` + `aapt2`**

### 2. 后端实现（electron/adb.js）

新增函数：

```javascript
// 获取已安装app列表
export async function getInstalledApps(serial) {
  // 1. pm list packages 获取包名列表
  // 2. 对每个包：pm path 获取apk路径
  // 3. 对每个包：aapt dump badging 获取app名称和图标路径
  // 4. 从apk中提取图标（使用aapt2或直接解压）
  return apps; // [{packageName, label, icon}]
}
```

### 3. 图标获取方案对比

| 方案 | 优点 | 缺点 |
|------|------|------|
| **aapt2 dump resources** | 可获取高清图标 | 命令复杂，解析困难 |
| **aapt dump badging** | 获取图标路径 | 需要额外步骤提取 |
| **直接解压apk** | 简单直接 | 需要临时文件 |
| **使用pm createSession** | Android原生方式 | 兼容性问题 |

**推荐：使用 `aapt2 dump badging` + `aapt2 dump resources`**

### 4. 前端实现

- 修改 `AppList.vue`：接入真实数据
- 添加loading状态
- 优化搜索性能（debounce）
- **分页加载**：先加载前20个，滚动到底部时加载更多
- **图标懒加载**：图标单独接口，异步加载

## 实现步骤

### Step 1: 后端ADB函数

在 `electron/adb.js` 中添加：

```javascript
// 获取已安装app列表（只返回包名和名称，不包含图标）
export async function getInstalledApps(serial) {
  await ensureServer();

  // 1. 获取包名列表（全部app）
  const packagesOutput = await adbShell(serial, 'pm', 'list', 'packages');
  const packages = packagesOutput
    .split('\n')
    .map(line => line.replace('package:', '').trim())
    .filter(Boolean);

  // 2. 批量获取app名称（并行执行，但限制并发数）
  const apps = [];
  for (let i = 0; i < packages.length; i += 10) {
    const batch = packages.slice(i, i + 10);
    const results = await Promise.all(
      batch.map(async (packageName) => {
        try {
          const label = await getAppLabel(serial, packageName);
          return { packageName, label };
        } catch {
          return { packageName, label: packageName.split('.').pop() };
        }
      })
    );
    apps.push(...results);
  }

  return apps;
}

// 获取app名称
async function getAppLabel(serial, packageName) {
  try {
    const dumpsys = await adbShell(serial, 'dumpsys', 'package', packageName);
    const match = dumpsys.match(/nonLocalizedLabel=([^\s]+)/);
    if (match) return match[1];
    return packageName.split('.').pop();
  } catch {
    return packageName.split('.').pop();
  }
}

// 获取app图标（单独接口，懒加载）
export async function getAppIcon(serial, packageName) {
  try {
    // 获取apk路径
    const pathOutput = await adbShell(serial, 'pm', 'path', packageName);
    const apkPath = pathOutput.replace('package:', '').trim();
    if (!apkPath) return null;

    // 使用aapt2获取图标
    const aapt2Output = await adbShell(serial, 'aapt2', 'dump', 'badging', apkPath);
    const iconMatch = aapt2Output.match(/application-icon-\d+:'([^']+)'/);
    if (!iconMatch) return null;

    const iconPath = iconMatch[1];

    // 从apk中提取图标并返回base64
    const iconData = await adbShell(serial, 'unzip', '-p', apkPath, iconPath);
    return Buffer.from(iconData, 'binary').toString('base64');
  } catch {
    return null;
  }
}
```

### Step 3: 前端接入

修改 `src/components/home/AppList.vue`：

```javascript
import { useAdb } from '../../composables/useAdb'

const { getInstalledApps, getAppIcon } = useAdb()
const allApps = ref([]) // 所有app
const displayApps = ref([]) // 当前显示的app
const loading = ref(false)
const pageSize = 20
const currentPage = ref(1)

// 加载app列表
const loadApps = async () => {
  loading.value = true
  try {
    allApps.value = await getInstalledApps(props.serial)
    displayApps.value = allApps.value.slice(0, pageSize)
    // 开始懒加载图标
    loadIconsForVisibleApps()
  } catch (e) {
    console.error('获取app列表失败:', e)
  } finally {
    loading.value = false
  }
}

// 懒加载图标
const loadIconsForVisibleApps = async () => {
  for (const app of displayApps.value) {
    if (app.iconLoaded) continue
    try {
      const icon = await getAppIcon(props.serial, app.packageName)
      if (icon) {
        app.icon = icon
        app.iconLoaded = true
      }
    } catch {
      // 忽略图标加载失败
    }
  }
}

// 滚动加载更多
const loadMore = () => {
  if (displayApps.value.length >= allApps.value.length) return
  currentPage.value++
  const end = currentPage.value * pageSize
  displayApps.value = allApps.value.slice(0, end)
  loadIconsForVisibleApps()
}

// 搜索过滤
const filteredApps = computed(() => {
  if (!searchText.value) return allApps.value
  const keyword = searchText.value.toLowerCase()
  return allApps.value.filter(app =>
    app.label.toLowerCase().includes(keyword) ||
    app.packageName.toLowerCase().includes(keyword)
  )
})

// 搜索时重置显示
watch(searchText, () => {
  currentPage.value = 1
  displayApps.value = filteredApps.value.slice(0, pageSize)
  loadIconsForVisibleApps()
})
```

在模板中添加滚动监听：

```vue
<ScrollAreaRoot class="h-0 flex-1">
  <ScrollAreaViewport
    class="h-full w-full"
    @scroll="(e) => {
      const { scrollTop, scrollHeight, clientHeight } = e.target
      if (scrollHeight - scrollTop - clientHeight < 50) loadMore()
    }"
  >
    <!-- ... -->
  </ScrollAreaViewport>
</ScrollAreaRoot>
```

## 风险与注意事项

1. **aapt2可用性**：部分设备可能没有aapt2命令
2. **权限问题**：某些系统app可能无法获取图标
3. **性能问题**：大量app时加载可能较慢，建议分批加载或懒加载
4. **图标格式**：不同Android版本图标格式可能不同（png/webp/adaptive）

## 替代方案

如果aapt2方案不可行，可以考虑：
- 使用 `adb shell am` 启动app的Intent来间接获取图标
- 使用第三方库如 `adbkit` 解析apk
- 在前端使用默认图标，只显示名称
