## 镜像窗那层 chrome 涂装收成「一个 div」（第四稿）

- 用户报：「上边和右边的边框以及左上角右上角右下角的圆角不协调，**不是一个图层**」→ 追问后一句点死：「左上角右上角右下角和上边右边**改成一个 div**」。**他说的是 DOM 结构，不是观感。**
- 改前：同一层浅灰涂装由**三个元素**画 —— `.mirror-titlebar` 一条臂、`.mirror-rail` 一条臂、`.mirror-main` 上三层 `radial-gradient` 补手机黑框三个圆角外侧的楔形；淡入还分两套（两条臂 `background-color` 可过渡、三块角 `background-image` 不可过渡）。
- 改后（`src/mirror/App.vue`）：
  - 新增 `.mirror-chrome`（模板里 `.mirror-body` 的第一个子元素，`position: absolute; inset: 0; background: #dcdfe3; opacity` 开关 + `transition` 用 `--rail-fade-in/out`）。
  - `.mirror-body` 加 `position: relative`；`.mirror-titlebar` / `.mirror-main` 各加 `position: relative; z-index: 1` ⇒ 手机画在涂装上面，**手机轮廓自己把中间挖掉** = 上臂 + 右臂 + 三个角那三块。
  - 左下角那块（10-12「左下角不要有边框」）用 `clip-path: polygon(...)` 切 `--frame-radius` 见方的方口挖掉。
  - 删掉三条旧规则（`.is-chrome:not(.is-fullscreen)` 下的 titlebar / rail 底色 + main 的三层 radial-gradient）与两条已无意义的 `transition: background-color`。
- 验证：`pnpm lint` / `typecheck` / `test`（581 passed）/ `npx vite build` 全绿；产物 `dist/assets/mirror-*.css` 里 `--radius: 40px`、`--frame-radius: calc(...)` 都在，`clip-path` 没被 minify 弄坏。
- **离屏核对怎么做的**（可复用）：`dist/` 用 `python -m http.server` 托管（`pnpm dev` 不行 —— `vite-plugin-electron` 会用系统 node 去起 Electron，`SyntaxError: The requested module 'electron' does not provide an export named 'BrowserWindow'` 直接把 dev server 一起带走）→ `agent-browser open http://127.0.0.1:5199/mirror.html` + `set viewport 483 882` + `eval` 补 `.is-chrome`（**不用改源码**）→ `screenshot` → PIL 逐点取色。实测：显形态上臂/右臂/三块角全 `(220,223,227)`、左下角那块 `(255,255,255)`（挖掉了）、左沿/下沿仍黑框 `(11,11,13)`、画面 `(0,0,0)`；收起态除画面外全透。⚠️ 浏览器里没有 macOS 那圈窗口圆角，三个窗角在离屏截图里是方的。
- 教训（用户当场点出来的）：这类"不协调 / 不是一个图层"的报障，**先读 DOM 与样式**；我先把截图逐像素量了一轮（结论：颜色一致、圆弧重合、无缝无色差），方向就错了。
